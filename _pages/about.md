我是 Huang Bo-Chien。這個部落格記錄我 vibe coding 做過的各種雜七雜八的東西——用 AI 輔助開發的遊戲 bot、逆向工程筆記、強化學習實驗、失敗的嘗試，以及其他突然想做的奇怪東西。

## 目前進行中的專案

- [**lf2-bot**](https://github.com/HuangBo-Chien/lf2-bot) — 用 Python + Chrome DevTools Protocol 驅動 Little Fighter 2 Remastered（Electron/Steam 版）的 bot 與強化學習訓練環境。從選單導航、狀態輪詢、按鍵注入，到 DQN / self-play 訓練都自己來。

## 關於 Vibe Coding

對我來說，vibe coding 是「描述你想要什麼，讓 AI 把它做出來，然後一起驗證它真的能動」的過程。重點不是不寫 code，而是把精力放在**定義問題、設計驗證、誠實記錄**上——這也是這個部落格想做的事：不只記成功，也記下失敗、誤判和死胡同，那些往往才是最有價值的部分。
